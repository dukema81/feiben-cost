# 飞奔成本管理系统 · 用户手册 v1.0

> 面向：成本会计、成本经理、生产统计、成本中心负责人
> 演示账号：admin / cost@2026　系统入口：`http://<服务器>/cost/`

---

## 0. 一分钟上手路径

```
① 成本中心与科目（口径）→ ② 产品与 BOM（标准成本基础）→ ③ 计算标准成本
→ ④ 建工单 / 领料 / 报工 / 核算 → ⑤ 归集费用（审批）
→ ⑥ 执行分摊 → ⑦ 计算差异 → ⑧ 看报表 → ⑨ 期末结账
```

首次使用建议按 ①→⑨ 顺序走一遍 2026-10 期间（系统已带演示数据）。

## 1. 成本驾驶舱

打开即见的六张卡 + 三张图：

- **直接归集成本**：本期已批准费用单合计；
- **分摊执行**：本期阶梯分摊总额与守恒校核差（应为 0.00）；
- **标准 vs 实际**：本期已完工工单的标准成本、实际成本与差异额；
- **成本差异率**：差异 ÷ 标准成本，超过 10% 标红；
- **预算执行率**、**未完工工单**、**期间状态**；
- 趋势图：近 6 期标准 / 实际 / 直接归集三条线；
- 底部「关账前自检」：三项闸口实时状态，红叉表示还不能结账。

> 顶部右侧「期间」下拉可切换会计期间，全站页面随之切换。

## 2. 主数据

### 2.1 成本中心

| 字段 | 说明 |
|---|---|
| 类型 | 生产 / 辅助 / 管理 / 销售 / 研发 |
| 人工费率 | 元/工时，用于标准成本的人工计算 |
| 制造费率 | 元/工时，用于标准成本的制费计算与工单预定分配 |
| 分摊顺序 | 数字越小越先分摊；**只能分给数字更大的中心** |
| 动因 | 人工工时 / 机器工时 / 面积 / 人数 / 直接成本 / 用量 |

列表里的「直接归集 / 分入 / 分出 / 净成本」= 本期费用归集 + 最新分摊批次的承接与摊出。

> 为什么管理、销售中心不参与产品成本分摊？因为它们是期间费用，直接进当期损益，不进产品成本。若企业有内部转移定价需求，请升级 v1.1。

### 2.2 成本科目

四大类别：材料、人工、制造费用、期间费用。归集方式「直接」= 可直接计入产品，「间接」= 先归集到中心再分摊。

### 2.3 产品与 BOM

- **标准工时**：单件加工工时，人工/制费标准成本 = 标准工时 × 中心费率；
- **BOM**：单位用量 ×(1+损耗率)× 标准单价 = 单件材料成本；
- 损耗率上限 20%（可在业务规则 `loss_limit` 调整），超过会被拒绝，防止误录。

点「BOM / 成本卡」可查看四格成本构成、BOM 明细与历史版本。

## 3. 标准成本

点「按期重算标准成本」→ 系统按当前 BOM 与中心费率重算全部在产产品，生成新版本（v2、v3…），旧版本状态转为「历史」。

- 每次重算都会留版本，方便追溯「标准为什么变了」；
- 「发布」可把某个历史版本重新置为生效版本；
- 若产品没有 BOM 或没有成本中心，会在提示里列出，按 0 计算。

**口径校验**：标准成本卡三项之和 = 单位标准成本，与手工 Excel 复算误差 ≤ 0.01 元。

## 4. 生产工单

### 4.1 建单

选产品、成本中心、计划数量、完工数量、在制完工进度（默认 100%，即假定在制已完工）。

### 4.2 三步入账

1. **领料**：物料编码 + 数量 + 单价 → 金额自动算；
2. **报工**：工时 + 工资率（留空取中心人工费率）；
3. **核算实际成本**：材料 + 人工 + 实际工时 × 制造费率，并按约当产量拆分完工与在制。

### 4.3 约当产量怎么算

```
在制数量   = 计划数量 − 完工数量
约当产量   = 完工数量 + 在制数量 × 在制完工进度
单位成本   = 实际成本合计 ÷ 约当产量
完工转出   = 单位成本 × 完工数量
在制成本   = 合计 − 完工转出
```

例：计划 3000、完工 2600、在制进度 60% → 在制 400，约当 = 2600 + 240 = 2840；
若合计成本 80 万元，则单位成本 281.69，完工转出 73.24 万，在制 6.76 万。

### 4.4 完工闸口

未核算成本的工单点「完工」会被拒绝——这是刻意设计，避免成本空白工单进入结账。

## 5. 费用归集

- 新建时可「保存草稿」或「直接提交审批」；
- **预算闸口**：提交后占用额超过预算 110% 直接阻断（提示已占用多少、超多少）；
- 批准 → 预算 `used` 增加，驳回 → 不影响；重复批准会被拒绝；
- 期间结账后，任何状态变更都会被拒。

列表上方四张卡显示各类别占比，方便一眼看出成本结构。

## 6. 成本分摊

### 6.1 原理

阶梯（顺序）分摊：辅助中心按顺序号从小到大，把「自身直接归集 + 上游分入」按受益中心权重全部摊出。

```
CC201 动力（顺序1）→ 注塑/冲压/装配
CC202 维修（顺序2）→ 注塑/冲压/装配
CC203 品质（顺序3）→ 注塑/冲压/装配
```

### 6.2 两条硬约束

1. **禁止回分**：只能分给顺序号更大的中心，否则保存规则时就报错「阶梯分摊禁止回分」；
2. **守恒**：分摊前合计 = 分摊出合计，校核差必须 0.00（不能整除时末位吸收尾差）。

### 6.3 操作

点「执行本期阶梯分摊」→ 生成批次 `AL202610-0001`，可点「明细」查看每一笔分摊（步骤、分出/分入中心、动因、权重、待摊金额、分摊额）。

> 重复执行会生成新批次，报表取最新批次。旧批次保留，便于审计对比。

## 7. 预算管控

- 按「期间 + 成本中心 + 科目」设定预算额度；
- 执行率 ≥90% 预警（橙）、>100% 超支（红）、>110% 进入阻断区（红）；
- 页面顶部会汇总所有预警/超支项，直接点名到中心与科目。

预算不是摆设：它真的会挡住费用提交。

## 8. 差异分析

### 8.1 五维分解

| 差异项 | 公式 | 管理层解读 |
|---|---|---|
| 材料价差 | (实际单价 − 标准单价) × 实际用量 | 采购议价 / 市场价格波动 |
| 材料量差 | (实际用量 − 标准用量) × 标准单价 | 工艺损耗 / BOM 不准 / 报废 |
| 工资率差 | (实际工资率 − 标准工资率) × 实际工时 | 加班结构 / 人员等级 |
| 效率差 | (实际工时 − 标准工时) × 标准工资率 | 生产效率 / 换线频次 |
| 制费耗费差 | 实际制费 − 实际工时 × 标准分配率 | 预定分配率法下通常为 0 |

**五项之和 = 总差异**，页面「校核」列显示 ✓ 即闭合；分位残差已统一归入材料量差。

### 8.2 等级

| 差异率 | 等级 |
|---|---|
| ≥ 10% | 重大不利 |
| 1% ~ 10% | 不利 |
| < 1% | 微小 |
| −1% ~ −10% | 有利 |
| ≤ −10% | 重大有利 |

正数为不利（超支），负数为有利（节约）。点「分解」看单个产品的逐项金额与公式。

## 10. 期间结账

### 三闸口

1. 无待审批费用单；
2. 无未完工工单（草稿 / 在生产）；
3. 本期已执行分摊。

三条全绿才允许结账。结账后该期间费用单、工单、分摊、预算写入全部 409 拒绝。

**反结账**：仅系统管理员可操作，须填写原因，记入审计日志。

## 12. 常见问题

**Q：为什么分摊之后生产中心的净成本比直接归集大？**
A：净成本 = 直接归集 + 从辅助中心分入。辅助中心（动力、维修、品质）的净成本会归零，因为已全部摊出。

**Q：工单完工数量能大于计划数量吗？**
A：不能。超产请拆分新工单，或在计划数量上修正后重新核算。

**Q：差异算出来 0.00 是什么情况？**
A：本期该产品实际成本与标准成本完全一致（多见于标准成本刚按实际重算过），或该产品没有已完工工单。

**Q：结账时提示「仍有未完工工单」怎么办？**
A：把在制工单做完工（需先核算成本），或对跨期工单做关闭处理；确实要在制的，请把完工数量与在制进度录准确后再完工。

**Q：能否与 ERP / WMS 对接？**
A：可以。创建 scope=write 的 API Key，通过 `X-Fb-Key` 调用写接口；订阅 Webhook 可获得费用批准、分摊执行、期间结账等事件。完整契约见 `docs/api.md`。
